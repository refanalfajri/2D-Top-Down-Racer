WEB RACER — NEON SPRINT
=======================

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder web-racer.
3. Klik dua kali index.html atau buka melalui browser modern (Chrome, Firefox, Edge, Safari).

Kontrol desktop:
- ← / A : belok kiri
- → / D : belok kanan
- ↑ / W : gas
- ↓ / S : rem
- Space : mulai dari menu

Kontrol mobile:
- Gunakan tombol kiri, kanan, rem, dan gas di bawah arena.

Fitur:
- Endless vertical scrolling track
- Mobil lalu lintas sebagai rintangan
- Deteksi tabrakan dan layar game over
- Timer, jarak, dan speedometer
- High score tersimpan di localStorage browser

Catatan:
Game berjalan sepenuhnya di browser dan tidak membutuhkan server atau instalasi.
Font Google digunakan sebagai peningkatan visual; jika offline, font sistem akan digunakan.
